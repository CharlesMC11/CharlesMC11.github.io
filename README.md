# My Personal Website

Source code for my personal not-yet-commercial website. I originally had my
portfolio website on Adobe Portfolio while I was in school. But after I had
graduated, I tried using Jekyll and hosted it on GitHub pages.

During my Adobe Portfolio pages, I had some pages of my portfolio
password-protected, and would like to have that capability again later. Because
of that, I needed a backend server, and since I already knew Python, I might as
well use it.

I originally played with Django. But after learning more about it, and
realizing I don’t need many of its features, I decided to switch and play with
Flask.
